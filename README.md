# 疫情监测报告助手 v1.0

面向疾控机构及相关专业人员的本地离线疫情监测报告编制工具。

## 主要功能

- 支持周、月、旬、季、半年、年六类监测报告。
- 按表内结构识别九份本地Excel报表，支持文件夹读取和逐项选择。
- 提供地区、周期、文件重复等校验，以及病种选择和人工补充。
- 生成可编辑Word报告、图表及独立核对文件。
- 提供离线防控建议、趋势首段预览与人工编辑。

## 使用说明

计划支持Windows10/11 Intel/AMD 64位。正式包的安装启动方法以随包《使用说明.txt》为准。

报表处理和报告生成均在本机完成，不自动检查更新。使用者主动点击下载入口时，才调用浏览器访问GitHub。报告使用前须由专业人员核对数据、图表和建议。
